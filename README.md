# kipbingo
Bingo card for when [twitch.tv/kipbite](https://twitch.tv/kipbite/) plays horror games. Viewers can see any saved bingo cards at [kipbingo.com](https://kipbingo.com) and Kip/mods can access [kipbingo.com/admin](https://kipbingo.com/admin) to create a new bingo card, change the options available and check off bingo spaces. Once you get a row, bingo! The emotes will be pulled from Kip's twitch channel directly so they'll stay up to date.
